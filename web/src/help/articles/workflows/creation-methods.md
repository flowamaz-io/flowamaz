# Workflow Creation Methods

Flowamaz gives you six ways to create a workflow. They all produce the same thing — a
`flowamaz/v1` definition you can edit on the canvas or in YAML — so pick whichever
matches how the idea lives in your head right now.

## 1. Plain English (NL)

Describe the process in a sentence or two and the platform generates the nodes and
edges for you. **Use it** to go from idea to a working draft fastest, or when you're
not sure which node types you need.

## 2. Whiteboard / photo upload

Snap a photo of a flow you sketched on a whiteboard or sticky notes and upload it.
Vision parsing detects boxes, arrows, and labels, then proposes a canvas for review.
**Use it** when the process already exists on a wall, not in your head.

## 3. Conversation / Slack-thread paste

Paste a chat transcript or Slack thread where a process was discussed. Flowamaz
extracts the steps and decisions into a draft. **Use it** to turn "here's how we
actually do this" conversations into a real workflow.

## 4. Canvas drawing

Drag nodes onto the canvas and connect them by hand. **Use it** when you know exactly
what you want and prefer direct control over every node and edge.

## 5. YAML editor

Write the `flowamaz/v1` definition directly. **Use it** for precise edits, copy-paste
between workflows, code review, or anything version-controlled by hand.

## 6. Templates

Start from a pre-built workflow in the template gallery and adapt it. **Use it** to
skip the blank page for common patterns like approvals or data sync.

## Which should I use?

| Starting point | Best method |
|----------------|-------------|
| An idea in your head | Plain English |
| A sketch on a wall | Whiteboard upload |
| A chat where it was decided | Conversation paste |
| A clear mental model | Canvas drawing |
| Exact control or reuse | YAML editor |
| A common pattern | Templates |

Whatever you start with, the result is a **draft** you refine before publishing.

# Contributing

Thanks for helping improve Flowamaz.

- Branch from `develop` and open your pull request into `develop`.
- Commit messages follow Conventional Commits: `type(scope): description` (types: feat, fix, chore, docs, test, refactor, perf, security).
- CI must pass: build and tests for `cli/` and `vscode-extension/`.
- All contributors sign the Flowamaz Contributor Licence Agreement before a pull request is merged. The CLA Assistant bot asks you on your first pull request.

Connectors and workflow templates have their own repositories: `flowamaz-io/connectors` and `flowamaz-io/templates`.

# Contributing

Thanks for helping improve Flowamaz.

- Open your pull request against `develop`.
- Commit messages follow Conventional Commits: `type(scope): description` (types: feat, fix, chore, docs, test, refactor, perf, security).
- CI must pass: build and tests for `dotnet/`, `canvas/`, `cli/` and `vscode-extension/`.
- All contributors sign the Flowamaz Contributor Licence Agreement before a pull request is accepted. The CLA Assistant bot asks you on your first pull request.

**How your change lands:** this repository is published from Flowamaz's development repository. A maintainer applies an accepted pull request there (keeping you as the author). It returns here with the next export, and your pull request is closed with a link to it. It isn't merged directly.

Connectors and workflow templates have their own repositories: `flowamaz-io/connectors` and `flowamaz-io/templates`.
